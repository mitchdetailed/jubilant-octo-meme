### Deviations of the M3 contract from the design text

Recorded in D-193 (proposed): component body schemas as fragments with `$id`
`urn:esses:components/<type>-<version>`; no `common-1` (shared definitions repeated per schema, kept identical by
the checker); persisted limits `{v, unit}` only; the names added (`GaugeGeometry` and the typed bodies,
`ChannelUse`/`componentChannelUses`, `ScaleSpec`, `ColourBand`, `TrackFit`, `AnimationController`,
`ComponentClipboard`, `FieldKind`/`FieldBinding`, `ComponentBuildInputs::trackMap`, the report/track/binning
value types); `VarianceTable::build` takes a `VarianceRequest`; `TrendFit` without Eigen. Further, smaller:

- `PropertiesDialog::openFor` (not `open`, which would hide `QDialog::open()`; MSVC C4263).
- `HitResult` grew members, so the M1 builder sets them through a helper (`hitOf`) instead of a positional
  aggregate (GCC and Clang `-Wmissing-field-initializers`).
- An M3 drawn type whose builder is still a stub renders `OffscreenRenderer`'s "Render failed" placeholder
  instead of the plain type-name placeholder.
- `tst_worksheet_canvas` uses `gauge_dial` (a v1.0 type) as its unregistered component, now that
  `gauge_numeric` is registered.

  percent and time, the scatter grid, `TrendFit` by Givens QR, variance with lap stretch, `gCorrection`'s edges).
