## 5. Deviations from the design

1. **No `qt-app` CI job in M0** (07 §3.1): no Qt code exists yet; the job arrives with the first Qt target in M1.
   Recorded as D-150.
2. **No vcpkg** (07 §3.1, 08 §3.7): every dependency is vendored under `third_party/` (`third_party/README.md`),
   so CI fetches nothing but the toolchain. Recorded as D-147 (Catch2 and its test discovery: D-148).
3. **No `CLAUDE.md`/`AGENTS.md`** (08 §1, R-08 mitigation): not an M0 criterion; deferred to M1. Recorded as D-151.
4. **`fixture add` defaults** differ from the 07 §3.6 step-4 command as first written: `--licence` is required for a
   public fixture and `oracle.validity` defaults to `finite-only` for the reference decoder (07 §3.6 updated). Recorded as
   D-152.
5. **`.ld` reader rules amended after the review** (05 §3.5 and §3.8, `docs/formats/ld.md`): storage dtype of
   scaled integers and u32; C-series record rules keyed on the logger layout; the [mi2] fingerprint; reversed gap
   pairs; terminator only when all zero and last; new Info codes `ld.gap_block_shared`, `ld.gap_convention_shifted`,
   `ld.enum_index_duplicate`, `ld.enum_ref_ignored`.
6. **Device-event labels** reworded (Esses' own wording); the `markers-1`/`laps-1`/`probe-1` examples and goldens follow.
