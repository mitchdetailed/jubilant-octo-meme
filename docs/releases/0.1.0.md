Esses 0.1.0 is the first public alpha of Esses, a free, open-source desktop application for analysing motorsport
data logs. It opens `.ld` log files (with their `.ldx` companions) and CSV exports, lets you choose laps to
compare, and shows them in graphs, reports and gauges, with maths channels written in the syntax of MoTeC i2.

0.1 covers a day at the circuit: opening the logs, comparing laps, graphs, reports and maths. It is an alpha, so
expect rough edges, and please [report them](https://github.com/mitchdetailed/jubilant-octo-meme/issues) (see
Reporting problems below).

## Installing

[Installing Esses](https://github.com/mitchdetailed/jubilant-octo-meme/blob/v0.1.0/docs/user/install.md) covers
every package, the portable mode and the command line. In short:

- **The packages are not code-signed.** On Windows, SmartScreen may say it protected your PC: choose
  **More info**, then **Run anyway**. On Windows 11 with Smart App Control turned on, Windows blocks unsigned
  programs and offers no Run anyway; Esses then runs only with Smart App Control turned off (Windows Security >
  App & browser control > Smart App Control settings), which applies to every program, and on a Windows 11
  without the latest updates it cannot be turned on again without reinstalling Windows. On macOS the first start
  is refused. On macOS 14, Control-click (or right-click) Esses in Finder, choose **Open**, then **Open** again.
  On macOS 15 or later, try to open Esses once, then choose **Open Anyway** in System Settings > Privacy &
  Security. Later starts work normally.
- **The Windows installer** can associate `.ld` files with Esses (unticked if another program already opens
  them) and makes sure the Microsoft Visual C++ runtime is new enough: installed for all users, it installs the
  runtime it carries when yours is missing or too old; installed for your user only, it puts the runtime files
  beside Esses. The portable zip includes the runtime files and keeps its settings in its own folder.
- **To check a download**, compare its checksum with `sha256sums.txt`: on Windows
  `Get-FileHash <file> -Algorithm SHA256` in PowerShell, on Linux `sha256sum -c sha256sums.txt --ignore-missing`,
  on macOS `shasum -a 256 <file>`.

Help > About Esses (or `esses --version`) shows the version, the commit it was built from and the Qt version.

## What is in 0.1

- Open several `.ld` files (merged with their `.ldx`) and CSV files at once, with an Import Log and a Mapping
  panel for unknown units and channel names.
- The Data window: a Main lap and overlays, filters, lap times, the difference to the fastest lap, offsets and
  trust flags.
- Workbooks of worksheets: time and distance graphs, an outing graph, scatter plots, histograms, channel and time
  reports, track position, a values list and numeric and bar gauges, with linked cursor, zoom and datum. A
  default circuit workbook is included.
- Global and local maths channels with live diagnostics, and a Channel Status window that shows where each
  channel comes from.
- Corrected speed and distance, lap stretching and a Track Editor for track maps and sections.
- Projects that autosave and reopen with the same laps selected.
- A complete key-binding table and a command palette (CTRL+SHIFT+P).
- A memory budget: before a file is loaded, Esses estimates the memory it needs and warns when that is above the
  budget (a quarter of the computer's memory by default, at least 1 GB), with Continue and Cancel. The status
  bar's Performance field shows what is in use.
- Files that change on disk are marked stale and can be reloaded with the same laps selected.
- Each monitor's display scale is followed: a window moved to a monitor with another scale is redrawn at that
  scale.
- `esses-cli` for scripts: `info`, `channels`, `laps`, `eval`, `export`, `convert`, `validate` and more.
- A user guide: F1 opens it.

## Known limitations

- **Not in 0.1 yet:** importing workbooks, maths or settings files from other analysis software (you rebuild
  your worksheets), an indexed file browser, printing, a GPS correction dialog, and Drag or Rally profiles.
- **Linux and macOS** are not supported in 0.1 (above).
- **At a display scale of 200 %**, grid lines, axis ticks and the cursor are drawn over three device pixels at
  half, full and half strength, so they look slightly soft. At 100 %, 125 % and 150 % they are sharp. Crisp lines
  at 200 % are planned for a later release.
- **Tables** (reports, the Values window, the dock lists) are drawn by Qt, and their thin grid lines can look
  slightly uneven at 125 % and 150 %.
- **Programs that write logs while Esses has them open.** While Esses has a log open, Windows refuses a program
  that overwrites that file in place, and some programs that replace it with a new copy. If a logging or download
  program reports that it cannot write a log, close that file in Esses first. When a program does replace an
  open file, Esses marks it stale, at the latest the next time Esses becomes the active application, and
  File > Reload File reads the new copy. A replacement with exactly the same size and modification time is not
  noticed: close the file and open it again.
- **The memory budget is a warning only.** Data that is loaded stays loaded until you close its file.
- **Replacing Qt** (the LGPL re-linking right) works with a build of the same Qt version only, 6.12.0 for these
  packages ([Replacing the Qt libraries](https://github.com/mitchdetailed/jubilant-octo-meme/blob/v0.1.0/docs/user/relinking.md)).

## Licences and source

Esses is MIT-licensed; the source of this release is the tag
[`v0.1.0`](https://github.com/mitchdetailed/jubilant-octo-meme/tree/v0.1.0). The application packages include
Qt 6.12.0 (LGPL-3.0-only) and the Qt Advanced Docking System 5.1.1 (LGPL-2.1-or-later), both linked dynamically;
the command-line archives contain neither. Qt is unmodified. Esses fixes two defects in the docking library's
source that the upstream project has not fixed; the changes are listed in
[`third_party/qtads/UPSTREAM.md`](https://github.com/mitchdetailed/jubilant-octo-meme/blob/v0.1.0/third_party/qtads/UPSTREAM.md).
Both libraries' upstream source archives are attached to this release.
[NOTICES.md](https://github.com/mitchdetailed/jubilant-octo-meme/blob/v0.1.0/NOTICES.md) lists the third-party
components with their licences and the source offer for Qt and the docking library; each package's
`THIRD_PARTY_LICENSES.md` lists what that package contains.

## Reporting problems

Problems and ideas go to the
[issue tracker](https://github.com/mitchdetailed/jubilant-octo-meme/issues). Issues are public, so keep private
data out of them:
[Reporting a problem](https://github.com/mitchdetailed/jubilant-octo-meme/blob/v0.1.0/docs/user/troubleshooting.md#reporting-a-problem)
says what to include and what to leave out. Report security problems privately: the repository's Security tab
has "Report a vulnerability".

"Esses" is the project's working name. Esses is an independent project: it is not affiliated with, endorsed by or
supported by MoTeC, and it contains none of MoTeC's software, help text or files.
