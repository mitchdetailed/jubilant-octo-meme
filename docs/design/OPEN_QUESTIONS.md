# Open questions

This page lists every decision that is still open, in the order it is needed. It has three parts. **A** holds the user's decisions: the consolidated list Q-01–Q-18 at the end of `DECISIONS.md`, which covers every ADR and Addendum A entry marked "User must confirm". **B** holds checks against a real environment or an i2 install. **C** holds design follow-ups raised by the revisers that the document owners settle. Each row gives the recommended default the design already proceeds on and what changes if you choose otherwise. Unless a row says **Blocking**, work continues on the default until you answer. Since 2026-10-10 no row is blocking: Q-01 to Q-05 are answered, so nothing blocks the first push or the first commit of `CLEANROOM.md`, and M0 can start.

Phases: **Before M0** means before the first push, before the first commit of `CLEANROOM.md`, or in M0 week 1. **Before M2** means by the start of M1 or M2. **Later** means M3 or after.
